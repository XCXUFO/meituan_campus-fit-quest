# 校园运动星球 Campus Fit Quest

> 面向高校学生的运动激励与周边权益连接平台。

[产品文档](PRODUCT.md) | [技术文档](TECH.md)

## 在线 Demo

[https://xcxufo.github.io/meituan_campus-fit-quest/](https://xcxufo.github.io/meituan_campus-fit-quest/)

当前项目是零依赖静态 Web Demo，仓库根目录即可直接托管。

如果链接首次打开为 404，请在 GitHub 仓库中开启一次 Pages：

1. 进入 `Settings` → `Pages`
2. `Build and deployment` 选择 `Deploy from a branch`
3. Branch 选择 `gh-pages`，目录选择 `/ (root)`
4. 保存后等待 1-2 分钟

## 一句话介绍

校园运动星球以“和过去的自己比赛”为核心激励思路，通过低门槛任务、低电量模式、复活任务、寝室/社团轻社交挑战和周边商家权益，帮助大学生更轻松地开始运动、重新开始并持续运动。

## 当前 Demo 完成度

- 390x844 手机模拟器容器，移动端自动全屏适配。
- 首次启动隐私弹窗、手机号/微信/Apple/游客登录入口、协议勾选。
- 5 个底部 Tab：今日、挑战、权益、星球、我的。
- 今日页支持 4 种状态模式、任务完成、能量奖励、徽章解锁和离线模拟。
- 校园跑完整流程：路线选择、SVG 校园地图、模拟点位到达、完成奖励。
- 挑战页覆盖寝室协议、社团挑战、全校挑战、运动搭子。
- 权益页包含兴趣分析、合作商家标识、领取流程和模拟核销码。
- 星球页包含动态星球、与上周的我对比、个人最佳记录、徽章墙。
- 我的页覆盖权限管理、个人信息管理、推送风格、设备管理、青少年模式、协议、隐私政策、注销流程、备案与投诉入口。
- localStorage 持久化，支持评委刷新后继续体验，也支持一键重置数据。

## 核心差异化

1. 不是榜单竞争，而是和过去的自己比较。
2. 不是只奖励连续打卡，也奖励中断后的重新开始。
3. 不是严肃说教，而是星球小助手式的趣味陪伴。
4. 不是只做线上激励，而是用周边权益承接真实健身需求。

## 技术说明

原技术文档规划为 React 18 + Tailwind CSS + Vite。当前面试 Demo 为了保证在时间紧、网络依赖不稳定的情况下可直接部署，采用零依赖静态实现：

- `index.html`
- `styles.css`
- `app.js`
- localStorage
- SVG 可视化

这保证 GitHub Pages 可以直接从仓库根目录打开，无需安装依赖和构建。

## 第三方软件能力边界

本产品作为第三方软件，边界清晰：

- 可独立完成：产品功能、用户运动数据、轻社交关系、规则推荐、提醒系统。
- 需合作支持：周边商家权益、社团共创、健身机构体验课。
- 长期推动：校方深度合作、教务系统互通、硬件点位部署、官方认证。

明确不承诺：直接加学分、接入教务成绩系统、一上线覆盖所有学校、完美运动防作弊。
